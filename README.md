# One Display

One Display is a little Mac utility that automatically turns off your MacBook’s built-in display while an external display is connected. There are a few reasons why you might want to do that:

* Multi-display setups can be overwhelming and tedious to manage.
* If you use your MacBook in clamshell mode with an external keyboard and mouse, you lose access to Touch ID and the front-facing camera.
* The Magic Keyboard, Magic Mouse, and Magic Trackpad can only be paired to one Mac at once, so switching your desk setup between two MacBooks is difficult.

It has a few other tricks to help you manage your display setup:

* You can turn on and off the internal display with a keyboard shortcut, useful if you do occasionally need the extra space.
* It can remember where your windows were positioned on each display and restore those positions when you attach or detach your external display. (macOS is somehow still really bad at this, after all these years.)

One Display is free and open source. If you find it useful, encounter bugs, or have thoughts about how I can make it better, I’d love to hear from you!
